# Final Project: Hybrid Enterprise Application

This folder assembles a single architecture that forces the lab to use Linux and Windows workloads together:

- Linux frontend
- Java API gateway
- Kafka
- Redis
- Prometheus
- Grafana
- Windows ASP.NET Framework app
- Windows background worker
- SMB storage
- Active Directory / gMSA integration

The goal is to turn the earlier modules into one coherent architecture, deployment sequence, and troubleshooting exercise.
